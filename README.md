Welcome to the debugging challenge! This branch contains the MPPT code that was not working as expected

### How submission will be handled

1. **Fork the Repository:** Start by making of fork of the repository
2. **Implementing your proposed solution:** Adjust the code as you deem necessary
3. **Submit a Pull Request (PR):** Submit a Pull Request back to this branch. In your PR description, briefly explain what the issue was and how your code attempts to tackle it

### Review Process & Deadline

* **Continuous Updates:** You are allowed to update and push new commits to your PR as many times as you want up until the deadline.
* **Review & Feedback:** I will be reviewing all submissions. If time permits, I may leave feedback on your Pull Request, giving you the opportunity to revise and improve your solution before the deadline hits. 

### Participation bonus 
* Remember that the bonus points are on you engaging with other to reach solutions, head over to the discussions tab, introduce yourself and start talking

Good luck
